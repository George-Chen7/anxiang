# 安响｜从社区沙盘到一户客厅

打开网页先看到「安响」和一座缓慢旋转的社区。下滑时，镜头找到其中一扇窗，外墙沿窗框剖开，露出一户客厅。观众随后能亲眼追踪同一条告警，从左边墙上的检测器，一直看到右边社区监控台上的「待核实」。

## 第一屏 · 社区

左侧约三分之一留给大标题「安响」，下方一行项目介绍「为独居老人发现居家异常，提醒社区及时核实」，主按钮写「进入登录」。右侧让现有五栋住宅尽量占满画面，保留参考图的白色楼板、灰绿窗带和长投影。底座可以越出右边界，楼顶与目标住户的窗户要留在画面内。

开场第一帧就显示完整建筑。前 1.2 秒相机从略低的角度抬升，前后两排楼产生视差，阳台挑板依次接到侧光。相机落稳后沙盘缓慢自转，允许拖动、暂停。首屏底部的「下滑，走进一户人家 ↓」也可点击。

## 两屏之间 · 剖开一扇窗

这是优先打磨的镜头。以一次从第一屏到第二屏的滚动距离为 100%，画布在这段距离内固定，滚轮和触摸维持浏览器原生行为。

| 滚动位置 | 画面与实现 |
| --- | --- |
| 0–25% | 接住当前旋转角度，镜头沿短弧线转向目标窗户。其他楼栋标签收起，目标窗框亮起暖白轮廓。 |
| 25–65% | 相机靠近窗沿，前景阳台从画面边缘掠过。窗框始终对准同一屏幕位置，避免镜头扫过目标。 |
| 65–85% | 裁切平面沿外墙推进，断面露出一条细亮边。让预置客厅与窗框的位置、朝向、光线吻合，观众可以看到沙发和墙上的检测器。 |
| 85–100% | 镜头退半步，让整个客厅落在左半屏，右侧露出社区监控台。场景稳定后才开始人物动作。 |

先用单栋楼与空房间验证窗框对齐。任意位置停止滚动，镜头都应停住；向上回滚应沿原路退出。镜头的滚动进度可参考 [GSAP ScrollTrigger 的 scrub 与 pin 示例](https://gsap.com/docs/v3/Plugins/ScrollTrigger/)，墙体剖切可直接体验 [Three.js 裁切交互示例](https://threejs.org/examples/webgl_clipping_intersection.html)。

## 第二屏 · 一条告警如何抵达社区

左侧采用开顶、去前墙的客厅模型。一张沙发、一盏落地灯和一块地毯用来交代空间尺度，给人物侧面留出清晰轮廓。右侧是深墨绿色社区监控台，保留楼栋简图、事件列表与状态三个要素。监控台旁有独立的「进入登录」按钮，整段演示随时可进入登录页。

| 时间 | 左侧客厅 | 右侧监控台 |
| --- | --- | --- |
| 0–4 秒 | 老人从沙发旁走出两三步，脚掌交替着地。墙面检测器保持微亮。 | 显示社区简图与「等待事件」。 |
| 4–6 秒 | 一步踩偏，膝盖先弯、手臂伸出、身体侧落，最后停在地毯边。人物投影随重心降低而收紧。 | 保持安静，让观众看完动作。 |
| 6–8 秒 | 检测器红灯缓慢亮灭两次，墙面出现微弱红色反光。标注「疑似跌倒」。 | 此时仍在等待接收。 |
| 8–10 秒 | 一枚带短尾迹的红色光点从设备出发，沿细线越过画面中线。 | 光点抵达同一栋楼的位置，落点扩散出一圈涟漪。 |
| 10–13 秒 | 保留房间与人物终态，设备灯转为常亮。 | 落点旁的住户标签移动到列表首行并展开，显示楼栋、房间、「疑似跌倒」和「待核实」。 |

跨屏光点的起点取自检测器三维坐标投影，终点取自监控台楼栋标记的实际屏幕坐标。这样调整窗口宽度后，信号仍会准确落到楼上。告警卡展开时让文字保持原字号，只改变容器边界和位置；这种从地图标记连续变为详情的做法可参考 [GSAP Flip 官方交互演示](https://gsap.com/docs/v3/Plugins/Flip/)。

右下提供「暂停」和「重播演示」。播完停在待核实状态，重播时一并清空指示灯、信号轨迹和事件卡。页面标明「场景演示」，用本地时间线驱动整段动作。

## 实现顺序与验收

1. **先做穿窗样片。** 从现有 Three.js 社区建模代码中复用楼体与材质，在同一画布中安排相机、剖切面和目标房间。分别从默认视角和手动旋转后的视角下滑，检查遮挡、跳帧和窗框对齐。
2. **再做接警样片。** 先把行走、失衡、落地三段动作做清楚，再接入红灯、跨屏信号与事件卡。无声播放一次，观众应该能指出哪户发生了什么、社区何时收到提醒。演示数据留在页面内存。
3. **接入口并适配。** 本地服务默认打开介绍页，两屏按钮均指向现有登录页。手机采用上方房间、下方监控台，信号路径随布局转为向下。减少动态效果模式直接展示社区全景与分步事件，后台标签页暂停渲染。

验收时优先看三处：快速滚到底能否完整看到跌倒过程，反向滑动时窗户能否与楼体重新对齐，以及演示进行中点击任一登录入口能否立即进入登录流程。首轮只用仓库已有 Three.js 和浏览器动画能力；上面的案例用于对照镜头和运动效果。
